## Key Findings

- **Baseline (Clean)**: ρ≤10px = 99.0%, θ≤2° = 100.0%
- **Most Robust Against**: 轻度反光 (ρ≤10px = 100.0%, drop = -1.0%)
- **Most Challenging**: 噪声 σ=30 (ρ≤10px = 5.0%, drop = 94.1%)
- **Angle Robustness**: Average θ≤2° drop = 12.6% (highly robust)
