## Key Findings

- **Baseline (Clean)**: ρ≤10px = 94.4%, θ≤2° = 98.9%
- **Most Robust Against**: 低清 0.5x (ρ≤10px = 95.1%, drop = -0.7%)
- **Most Challenging**: 压缩 Q=10 (ρ≤10px = 19.0%, drop = 75.4%)
- **Angle Robustness**: Average θ≤2° drop = 7.7% (highly robust)
